## 修复：恢复状态面板右侧呼出把手

### 根因
commit `379a0a7`（v2.0.6）在 `RemoteConnectionView.vue` 给 `<ServerDashboard>` 加了 `v-if="showDashboard"`。面板隐藏是靠 CSS `.is-hidden { transform: translateX(100%) }` 平移出屏幕，吸边把手 `.toggle-handle`（面板收起时的呼出入口）常驻右边缘。`v-if` 条件挂载导致收起时整个组件（含把手）被销毁，面板再无呼出入口。

### 改动
单个文件、一行删除：
- `src/components/connections/RemoteConnectionView.vue` L1353：删除 `v-if="showDashboard"`，恢复常驻挂载 `<ServerDashboard :show="showDashboard" ...>`

### 为什么安全
- CSS（`.is-hidden` 平移、隐藏态把手样式、`.has-active` 上传脉冲）、`watch(showDashboard)` 图表历史回填、700ms/3s 自适应轮询全部按常驻挂载设计，删除 v-if 即恢复设计行为
- 拖文件上传自动弹出（`confirmUploads` → `showDashboard.value = true`）、切换 session 重置历史、`@toggle` 事件逻辑均不受影响
- 组件随父组件 `RemoteConnectionView` 卸载而销毁，无泄漏

### 验证
- `pnpm lint`、`pnpm build`（vue-tsc 类型检查）通过
- 手动/开发模式验证：连接后右边缘出现吸边把手，点击可呼出/收起状态面板；上传任务进行中把手显示金色脉冲
